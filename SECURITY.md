# Security policy

Humanizer v3.8.1 is a skills-only plugin with no MCP server, authentication flow, secret storage, independent telemetry, or external network service operated by the publisher.

If you discover a security issue in the package, report it privately through GitHub's security-reporting features when available for this repository. Do not post access tokens, credentials, private conversation content, or exploit details in a public issue.

Reports should identify the affected version, file or behavior, reproduction steps that do not expose sensitive data, and the expected security property.
