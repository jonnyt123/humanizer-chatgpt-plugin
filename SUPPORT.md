# Support

Use GitHub Issues for Humanizer support:

https://github.com/jonnyt123/humanizer-chatgpt-plugin/issues

When reporting a reproducible problem, include the Humanizer version, the product surface you used (ChatGPT or Codex), the prompt shape, the expected behavior, and the actual behavior. Redact private, copyrighted, confidential, or personally sensitive source text before posting it publicly.

For a suspected security issue, follow `SECURITY.md` and do not post credentials, tokens, or private data in a public issue.
