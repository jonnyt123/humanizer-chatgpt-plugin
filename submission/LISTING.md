# Suggested plugin listing

## Name
Humanizer

## Short description
Humanize writing and optimize lyrics without flattening the writer's voice.

## Long description
Humanizer rewrites AI-sounding prose and lyrics while preserving meaning, concrete details, and voice. It can build a voice fingerprint from writing samples; score lyric artifact risk; analyze multisyllabic rhyme, pocket, cadence, and rhyme density separately; protect strong bars while repairing weak ones; optimize 16-bar verses and verse-to-hook transitions in context; use supplied BPM and meter for beat-grid-aware pocket analysis; and suggest bar-by-bar flow patterns.

Humanizer treats its scores as editing diagnostics, not proof that AI wrote a passage. For beat-aware analysis without performance audio or timestamps, it reports beat-grid compatibility rather than claiming exact microtiming.

## Category
Productivity

## Starter prompts
1. Humanize this paragraph while preserving my voice and every supported fact.
2. Learn my writing style from these samples, then rewrite this draft in the same voice.
3. Score these lyrics for AI-writing artifacts and rewrite only the weak lines.
4. Score this rap verse for multis, pocket, cadence, and rhyme density.
5. Improve the weak bars but freeze every strong line and show exact score changes.
6. At 142 BPM in 4/4, optimize this 16-bar verse and hook together.
7. Suggest the best flow pattern for each bar using the BPM, meter, lyrics, and surrounding bars.
